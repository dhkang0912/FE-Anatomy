# 💖프론트엔드 해부💖 (FE-Anatomy)
## 1. 개요
프론트엔드 마스터가 되어가기 위해 프론트엔드 기본부터 관련 내용들을 전반적으로 이해하고 이해한 내용을 기반으로 문제를 내거나 서로 가르쳐줌

## 2. 진행 목차
1. 브라우저 렌더링 과정
2. 리액트 렌더링 과정
3. 넥스트 렌더링 과정
4. 불변 객체, 실행 컨텍스트

## 3. 진행 방식
- 해당 repo를 fork하여 매주 스터디 전 정리한 내용과 퀴즈를 업로드함
- 커밋 메시지는 "[이니셜] - 내용" 으로 통일함
  - 예 : "[DH] - 브라우저 동작 원리 완료"
- 화, 목요일에 스터디 진행
